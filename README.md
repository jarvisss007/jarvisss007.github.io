# jarvisss007.github.io

Source of my portfolio site: **[jarvisss007.github.io](https://jarvisss007.github.io)**.

One page of plain HTML, CSS and JavaScript, no build step:

- the working papers and open-source toolkit, with live CI badges
- the AI research desk: agent-governance case studies, including [One Wrong Price](https://jarvisss007.github.io/qbts-case-study.html)
- an interactive hidden-Markov regime explorer: weekly S&P 500 since 1999, coloured by the fitted hidden states (`regimes.json` is exported from the model in [regime-monte-carlo](https://github.com/jarvisss007/regime-monte-carlo))

Run it locally by opening `index.html`, or serve the folder with `python -m http.server`.
